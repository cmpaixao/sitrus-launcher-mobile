SITRUS LAUNCHER MOBILE
======================

O jogador baixa um APK, instala no celular, coloca o nick e toca em Jogar.
O Sitrus baixa o pack e, na primeira vez, o motor do jogo. O Android pede
para instalar esse motor uma única vez. No Jogar seguinte, o pack abre sozinho.

Arquivo para enviar:
   dist\Sitrus-Launcher-Mobile-1.0.2.apk


1) O QUE O JOGADOR FAZ
----------------------

1. Baixa o APK e instala. O Android pede para permitir esta origem.
2. Abre o Sitrus Launcher.
3. Coloca um nick offline.
4. Toca em Jogar. A primeira vez baixa o motor do jogo e abre a instalação do Android.
5. Toca em Instalar. Volta ao Sitrus e toca em Jogar de novo.
6. O pack abre, baixa os mods e entra no Sitrus. A conta Microsoft entra nesse momento.
   O servidor sitruscobblemon.com já vem na lista.
   Se a instância pedir ajuste: 2 GB e MobileGlues.


2) GERAR O APK DE NOVO
----------------------

Precisa do Node.js e do Android SDK em C:\Android\sdk.

Na pasta "Laucher sitrus mobile":

   npm install
   npm run apk

O arquivo sai em dist\.


3) OLHAR NO COMPUTADOR
----------------------

   npm start

Abre http://127.0.0.1:4173
No navegador o pack também baixa, mas o arquivo que o jogador instala é o APK.
