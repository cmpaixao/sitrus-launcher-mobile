SITRUS LAUNCHER MOBILE
======================

O jogador instala o APK, coloca o nick e toca em Jogar.
O Sitrus baixa o modpack e abre no celular. Na primeira vez o Android
pede para instalar o jogo. Ao voltar, o pack abre sozinho.

Arquivo para enviar:
   dist\Sitrus-Launcher-Mobile-1.0.3.apk


1) O QUE O JOGADOR FAZ
----------------------

1. Baixa o APK e instala por cima do anterior.
2. Abre o Sitrus Launcher e coloca um nick offline.
3. Toca em Jogar. A primeira vez o Android abre a instalação do jogo.
4. Toca em Instalar e volta ao Sitrus. O modpack abre sozinho.
   A conta Microsoft entra nesse momento. O servidor já vem na lista.
   Se a instância pedir ajuste: 2 GB e MobileGlues.


2) GERAR O APK DE NOVO
----------------------

Precisa do Node.js e do Android SDK em C:\Android\sdk.

Na pasta "Laucher sitrus mobile":

   npm install
   npm run apk

O arquivo sai em dist\.


3) OLHAR NO COMPUTADOR
----------------------

   npm start

Abre http://127.0.0.1:4173
No navegador o pack também baixa, mas o arquivo que o jogador instala é o APK.
